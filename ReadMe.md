# AI-Assisted Peer Assessment Study

This repository provides the prepared study folder for students participating in the GenAI-Supported Peer Feedback Study.

## Download
AI-assisted-code-review.zip

After downloading:

1. Extract the ZIP file.
2. Open the extracted `AI-assisted-code-review` folder in **OpenCode Desktop**.
3. Follow the participant guide to connect your individual study API key.
4. Add your assigned peer projects and begin your peer assessment.

**Important:** Download the ZIP file. You do not need to clone this GitHub repository or install Git.

Your individual API key will be provided separately by the research team. Do not share it with others.
